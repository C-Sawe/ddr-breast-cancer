Model card

Read this before trusting a score. In cross-validation, 100 random sets of 158 genes separated tumour from normal just as well (AUC ≈ 0.999). DNA-repair genes carry a strong tumour signal, but much of it tracks cell proliferation, so it is not specific to repair.

Code, notebook and report on GitHub · Team: Ibrahim Sudheysi, Alvin Kimani, Latifah Jaafar, Caleb Kipchirchir, Jude Makau.

Validation: 5-fold cross-validation with each patient's tumour and normal kept in the same fold, repeated 3 times. Also checked on the 114 matched pairs and with whole hospitals held out. Most errors were PAM50 Normal-like tumours. Trained on one cohort and one platform: values from microarrays or other pipelines need re-normalising first. Research and teaching use only, not for diagnosis.
